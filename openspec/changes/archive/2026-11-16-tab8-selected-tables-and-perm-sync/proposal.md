# Proposal

## Why

在 Tab 8（三方开放 API 账号管理）中，单个数据源下往往包含上百张数据表，管理员在配置或核对授权表时只能上下滚动全量表列表逐行查看，极为不便；同时在新增或调整多个相似业务方账号时，缺少将已有账号的库表权限快速同步到目标账号的能力，只能重复人工勾选。

## What Changes

- **选表区增加“已选表查看”能力**：
  - 在当前数据源表控制条增加“全部 / 仅看已选”快速切换开关，支持与搜索框叠加过滤，方便立即核对和取消当前库已勾选的表。
  - 支持点击“已授权 X / Y 张表”徽标（或旁置纯文本“已选表”按钮）打开跨数据源已选表汇总查看弹窗，按库分组展示已授权表（含通配 `*` 标识），支持一键复制表名清单或快速移除单张表。
- **新增“从其他账号同步权限”能力**：
  - 在账号新增/编辑弹窗的“授权数据源库与表控制”区域新增“从其他账号同步”纯文本按钮，打开权限同步选择器。
  - 支持选择任意已有 API 账号作为来源，展示其已授权的数据源库清单，支持勾选**单个或多个数据源库**（并支持展开查看/微调单库下的已选表）。
  - 同步时支持显式选择合并策略：**追加合并**（保留目标账号现有表，对同名库取表集合并集）或**覆盖替换**（以来源账号的表集合覆盖同名库）。
  - 同步时显式提示并由管理员勾选**是否同时使用来源库的行级字段过滤规则**（默认不勾选，避免不同租户/业务方的过滤值误带入），同步结果先回填至当前弹窗工作区供核对调整，再随表单统一保存。

### Modified Capabilities
